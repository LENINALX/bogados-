# Bogados

Plataforma SaaS de gestión legal para firmas de abogados (MVP).

## Visión

Centraliza expedientes, documentos y comunicación segura entre abogado y cliente, con portal del cliente y multi-tenant desde el día 1.

## Stack

- Next.js (App Router) + TypeScript + Tailwind
- PostgreSQL + Prisma
- Auth.js (credenciales) con roles Admin / Abogado / Cliente
- Docker Compose para Postgres local
